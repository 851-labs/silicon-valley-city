# Source map

## Current pipeline

- `asset_core.py`: mesh primitives, materials, plants, signs and preview setup.
- `reference_geometry.py`: camera-space measurements, unprojection and shared lighting.
- `blender_runtime.py`: portable Cycles device selection.
- `build_measured_checkpoint.py`: the authoritative ordered list of current builders.
- `*_measurements.json`: per-building geometry and reference crops.
- `*_mesh.json`, `logo_shapes.json` and title contours: prepared vector/contour data.
- `catalog_assets.py`: Blender Asset Library catalog and manifest.
- `assemble_city.py`: placement, streets, landscape, cameras and lighting.
- `make_portable_city.py`: embeds linked assets for the standalone scene.
- `validate_measured_delivery.py`: saved-file geometry and dependency integrity.
- `render_measured_sunrise.py`: the morning lighting render.
- `refresh_measured_delivery.py`: ordinary Python wrapper for sequential Blender steps.
- `rebuild_all.py`: equivalent full rebuild inside one Blender process.
- `match_boards.py`, `review_fonts.py`, `create_measured_review.py`: local review output.
- `matching_status.json`: current visual comparison ledger.

`catalog_assets.py`, `assemble_city.py` and `make_portable_city.py` require
`--measured-checkpoint` after Blender's `--` separator for the current delivery.
The wrapper supplies these flags automatically.

## Research and earlier revisions

`prepare_*`, `trace_*`, `fit_*`, `refit_*`, `calibrate_camera.py` and
`extract_ebay_panels.py` record the tracing and fitting process. Many require
optional source images or historical vectors under `references/`. Reports of
rejected fits are retained for context; current measurements and builders take
precedence. `fit_asset_colors.py` runs in Blender; numerical/image fitting
scripts normally use the optional research Python environment.

Older builders such as `build_campuses.py`, `build_offices.py`, `build_landmarks.py`
and `build_title.py` also supply helpers to current builders, so they remain
beside them. The three historical alternatives are supplied as editable assets.
They are not generated by the measured-only rebuild.

`finish_v3.py`, `render_library_v3.py`, `create_review.py`, `validate_delivery.py`,
`package_project.py`, older `study_*` scripts and palette/relighting utilities
are historical tools. Some expect earlier city files, intermediate images or
macOS Metal/fonts. Those intermediate deliveries are not shipped in this
repository. Use the current pipeline above for a reproducible checkpoint.

The current measured signs use prepared meshes. Older text-based variants can
use fonts from `BLENDER_FONT_DIR`, falling back to Blender's built-in font when
the named system font is unavailable. Review labels accept `REVIEW_FONT`.
