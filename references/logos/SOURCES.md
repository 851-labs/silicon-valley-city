# Vector artwork sources

- Twitter bird: Twitter’s own open-source website artwork, commit 2887311216d99cd0e38b16e564bcdbea3797eb63. https://raw.githubusercontent.com/twitter/opensource-website/2887311216d99cd0e38b16e564bcdbea3797eb63/static/assets/twitter-logo.svg . Twitter artwork is distributed under Apache 2.0; shape used here with a color matched to the studio reference.
- Apple symbol: https://commons.wikimedia.org/wiki/File:Apple_logo_black.svg . Original designer Rob Janoff. The same silhouette is used for the white campus sculpture and historical rainbow sign.

The architecture and placement are reconstructed from yU+co’s production references. These files supply sign outlines only.

- Google 2013–2015 serif wordmark: https://commons.wikimedia.org/wiki/File:Google2013logo.svg ; official artwork attributed to Google, extracted from its original SEO guide. Vector contours replace substitute fonts.

- Historical YouTube vector sign: https://commons.wikimedia.org/wiki/File:YouTube_Logo_(2013-2017).svg ; artwork attributed to YouTube. Vector glyph contours, capsule and pale production extrusion are modeled separately.

- Intel 2006–2020 wordmark and swoosh: https://commons.wikimedia.org/wiki/File:Intel_logo_(2006-2020).svg ; vector contours reconstructed as raised rooftop geometry.

- eBay 2012 wordmark geometry: https://commons.wikimedia.org/wiki/File:EBay_logo.svg (2012 identity colours applied separately).

- PayPal pre-2014 official vector: https://commons.wikimedia.org/wiki/File:PayPal_logo_pre-2014.svg
- Pets.com historical sign lettering/paw: https://en.wikipedia.org/wiki/File:Petsdotcomlogo.png ; extracted vector contours retain glyph counters.
